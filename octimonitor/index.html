How it works

OctiMonitor is our own monitoring SDK. No third-party analytics, no identifiers.

1. Measure

Every frame, the app records frame time and CPU time, and the GPU time from Metal. No memory is allocated per frame.

2. Summarize

Every 30 seconds it computes p50/p95/p99, dropped frames, hitch time, memory and thermal state for each material.

3. Send

One small anonymous JSON report goes to the backend. The public key can only insert rows, never read them.

4. Aggregate

This page reads only aggregates, through a single read-only function, and refreshes every 10 seconds.

OctiMonitor on GitHub

p95 values per material and over time are frame-weighted means of each 30-second window's p95. Hitch time counts only frames that missed their display slot: under 5 ms/s is good, 5–10 is noticeable, over 10 is bad.
